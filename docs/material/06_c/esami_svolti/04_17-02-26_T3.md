# 6.19.4 — Appello del 17/02/2026 — Turno 3 — PoliBanca

## Traccia originale

> Il sistema bancario della Banca PoliBanca gestisce titoli a multipli interi di 100 €. Si progetti un sistema che consenta movimentazioni bancarie da un conto di appoggio a un altro, mantenendo un saldo sempre costante.
>
> **Esercizio 1 – Diagramma di flusso**: Definire un apposito diagramma di flusso che consenta di generare tutte le transazioni necessarie.
>
> **Esercizio 2 – Programmazione**: Si definisca un programma in grado di organizzare le transazioni in ordine crescente di valore assoluto, mantenendo sempre i saldi dei due conti costanti. Si generi un adeguato report in un file di testo.

## Strategia risolutiva

Abbiamo due conti: un **conto di appoggio** (sorgente) e un **conto principale** (destinazione). Le transazioni sono in multipli di 100 €.

Il saldo totale dei due conti deve rimanere **costante**: ogni movimento da un conto all'altro è un trasferimento, non una spesa. Se il conto A perde 100 €, il conto B guadagna 100 €.

Il programma:
1. Genera una lista di transazioni casuali (importi multipli di 100 €, positivi o negativi).
2. Le applica ai due conti, verificando che il saldo totale sia sempre costante.
3. Ordina le transazioni per valore assoluto crescente.
4. Genera un report su file.

"Saldo sempre costante" significa che `saldo_A + saldo_B = costante`. Una transazione da A a B riduce A e aumenta B dello stesso importo.

## Diagramma di flusso

```mermaid
flowchart TD
    A[INIZIO] --> B[Inizializza saldo_A = 5000, saldo_B = 3000]
    B --> C[tot_iniziale = saldo_A + saldo_B]
    C --> D[Genera N transazioni multiple di 100€]
    D --> E{Per ogni transazione}
    E --> F[saldo_A -= importo]
    F --> G[saldo_B += importo]
    G --> H{Verifica: saldo_A + saldo_B == tot_iniziale?}
    H -->|Sì| I[Altra transazione?]
    I -->|Sì| E
    I -->|No| J[Ordina transazioni per |importo| crescente]
    H -->|No| K[ERRORE]
    J --> L[Scrivi report su file]
    L --> M[FINE]
```

## Soluzione C

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define N_TRANSAZIONI 10
#define MULTIPLO 100
#define MAX_IMPORTO 1000

typedef struct {
    int importo;       // positivo: A→B, negativo: B→A
    int saldoA_dopo;
    int saldoB_dopo;
} Transazione;

void genera_transazioni(Transazione t[], int n) {
    for (int i = 0; i < n; i++) {
        int importo = (rand() % (MAX_IMPORTO / MULTIPLO) + 1) * MULTIPLO;
        if (rand() % 2 == 0)
            importo = -importo;
        t[i].importo = importo;
    }
}

int applica_transazioni(Transazione t[], int n,
                        int *saldoA, int *saldoB) {
    int tot_iniziale = *saldoA + *saldoB;

    for (int i = 0; i < n; i++) {
        *saldoA -= t[i].importo;
        *saldoB += t[i].importo;
        t[i].saldoA_dopo = *saldoA;
        t[i].saldoB_dopo = *saldoB;

        if (*saldoA + *saldoB != tot_iniziale) {
            printf("ERRORE: saldo non conservato!\n");
            return 0;
        }
    }
    return 1;
}

int confronta_abs(const void *a, const void *b) {
    int aa = abs(((const Transazione *)a)->importo);
    int bb = abs(((const Transazione *)b)->importo);
    return aa - bb;
}

void scrivi_report(const Transazione t[], int n,
                   int saldoA_iniz, int saldoB_iniz,
                   const char *filename) {
    FILE *f = fopen(filename, "w");
    if (f == NULL) {
        printf("Errore apertura %s\n", filename);
        return;
    }

    fprintf(f, "=== Report PoliBanca ===\n\n");
    fprintf(f, "Saldo iniziale A: %d €\n", saldoA_iniz);
    fprintf(f, "Saldo iniziale B: %d €\n", saldoB_iniz);
    fprintf(f, "Saldo totale: %d €\n\n", saldoA_iniz + saldoB_iniz);

    fprintf(f, "Transazioni ordinate per |importo|:\n");
    fprintf(f, "%-10s %-12s %-12s\n",
            "Importo", "Saldo A", "Saldo B");
    fprintf(f, "%-10s %-12s %-12s\n",
            "--------", "--------", "--------");

    for (int i = 0; i < n; i++) {
        char desc[32];
        if (t[i].importo > 0)
            snprintf(desc, sizeof(desc), "+%d (A→B)", t[i].importo);
        else
            snprintf(desc, sizeof(desc), "%d (B→A)", t[i].importo);

        fprintf(f, "%-10s %-12d %-12d\n",
                desc, t[i].saldoA_dopo, t[i].saldoB_dopo);
    }

    fclose(f);
    printf("Report salvato su %s\n", filename);
}

int main() {
    srand(time(NULL));

    int saldoA = 5000, saldoB = 3000;
    int saldoA_iniz = saldoA, saldoB_iniz = saldoB;

    Transazione transazioni[N_TRANSAZIONI];
    genera_transazioni(transazioni, N_TRANSAZIONI);

    printf("Saldo iniziale A: %d €\n", saldoA);
    printf("Saldo iniziale B: %d €\n", saldoB);
    printf("Saldo totale: %d €\n", saldoA + saldoB);

    if (!applica_transazioni(transazioni, N_TRANSAZIONI,
                             &saldoA, &saldoB)) {
        return 1;
    }

    qsort(transazioni, N_TRANSAZIONI, sizeof(Transazione),
          confronta_abs);

    printf("Saldo finale A: %d €\n", saldoA);
    printf("Saldo finale B: %d €\n", saldoB);
    printf("Saldo totale: %d € (invariato)\n", saldoA + saldoB);

    scrivi_report(transazioni, N_TRANSAZIONI,
                  saldoA_iniz, saldoB_iniz, "polibanca.txt");

    return 0;
}
```

### Spiegazione

| Funzione | Ruolo |
|----------|-------|
| `genera_transazioni` | Crea N importi casuali multipli di 100, con segno casuale |
| `applica_transazioni` | Applica ogni transazione ai saldi, verificando che il totale resti costante |
| `confronta_abs` | Funzione di confronto per `qsort` che ordina per valore assoluto |
| `scrivi_report` | Scrive su file il report con transazioni ordinate e saldi |

Il **saldo costante** è garantito dalla proprietà: `saldoA` e `saldoB` variano in modo opposto della stessa quantità, quindi `saldoA + saldoB` non cambia mai. Il controllo esplicito nel ciclo `applica_transazioni` serve a verificarlo.
